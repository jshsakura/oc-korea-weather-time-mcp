무엇에 쓰는 물건인가What it is for

LLM 에이전트가 "지금 서울 몇 도야" 를 답할 수 있게 하는 것. 그게 전부다. Letting an LLM agent answer “how warm is it in Seoul right now”. That is the whole point.

모델은 오늘이 며칠인지, 지금 몇 시인지, 밖이 더운지 모른다. 학습 시점에 멈춰 있고 시계도 없다. 그래서 한국 시간과 한국 날씨를 물어보면 그럴듯한 숫자를 지어낸다. 이 서버는 그 두 가지를 실제 출처에서 가져다 준다 — 시간은 IANA 시간대 데이터, 날씨는 기상청. A model does not know today’s date, the current hour, or whether it is hot outside. It is frozen at training time and has no clock, so asking it about Korean time or Korean weather gets you a plausible-looking guess. This server fetches both from the actual sources — IANA timezone data and the Korea Meteorological Administration.

MCP 를 말하는 에이전트면 어디든 붙는다. 만들면서 실제로 물린 곳은 다음이다. It plugs into anything that speaks MCP. These are the hosts it was actually wired into while being built.

  • Hermes Agentstdio
  • GoClawstdio
  • OpenClawstdio
  • Claude Codestdio

텔레그램 봇으로 굴리는 개인 비서에 특히 잘 맞는다. "내일 아침 인천 비 와?" 한 마디에 단기예보의 강수확률까지 붙여서 답하게 하려고 만들었다. It fits personal assistants that live in a Telegram bot especially well — built so that “will it rain in Incheon tomorrow morning?” comes back with the actual precipitation probability attached.

툴 6 개Six tools

툴 정의는 매 요청마다 프롬프트에 실린다. 그래서 늘리지 않았다. Tool definitions ride along in every request, so the set is kept small.

날씨 · 기상청 단기예보Weather · KMA forecast
get_current_weather(location) 초단기실황nowcast 지금 관측된 기온·습도·강수형태·풍향·풍속Observed temperature, humidity, precipitation type, wind
get_hourly_forecast(location, hours) 초단기예보6-hour 앞으로 6 시간까지 시간별 예보Hour-by-hour forecast for the next six hours
get_daily_forecast(location, slots) 단기예보3-day 앞으로 3 일까지. 강수확률과 일최저·최고기온은 여기에만 있다Up to three days. Precipitation probability and daily min/max live only here
시간 · 표준 라이브러리만Time · stdlib only
get_current_time(timezone) zoneinfo 현재 시각 — UTC 오프셋·요일·유닉스초까지 같이 준다Current time, with UTC offset, weekday and epoch seconds
convert_time(time, from_tz, to_tz) zoneinfo 시간대 간 변환. 서머타임은 IANA 데이터가 처리한다Convert between zones; DST comes from the IANA database
find_timezone(query) zoneinfo IANA 시간대 이름 검색Search IANA timezone names

지역 지정Locations

위경도를 외울 필요가 없다. 생략하면 기본 지역을 쓴다. No coordinates to memorise. Omit it and the default location is used. 

# 이름·별칭·부분일치·좌표를 다 받는다# Names, aliases, partial matches and raw coordinates all work
get_current_weather("서울")
get_current_weather("부산광역시")
get_current_weather("성남시 분당구")
get_current_weather("37.5665,126.978")
get_current_weather()            → KMA_DEFAULT_LOCATION
지원하지 않는 지역을 넣으면 오류 응답에 지원 목록을 실어서 돌려준다. 목록 전용 툴을 두면 그만큼 매 요청 프롬프트가 무거워지기 때문이다. An unknown location comes back as an error carrying the supported list. A dedicated listing tool would cost prompt space on every single request.

등록Setup

uvx 가 실행 시점에 받아 띄운다. 설치 단계가 따로 없다. uvx fetches and runs it on demand — there is no install step. 

Claude Code
claude mcp add oc-korea-weather-time \
  -e KMA_SERVICE_KEY=… -e KMA_DEFAULT_LOCATION=서울 \
  -- uvx oc-korea-weather-time-mcp

mcp.json
{
  "command": "uvx",
  "args": ["oc-korea-weather-time-mcp"],
  "env": { "KMA_SERVICE_KEY": "…" }
}
공공데이터포털에서 기상청_단기예보 조회서비스 활용신청 후 일반 인증키(Decoding) 를 쓴다. 인코딩 키를 넣으면 이중 인코딩으로 인증에 실패한다. Request access to 기상청_단기예보 조회서비스 on data.go.kr and use the Decoding key. The encoded variant fails auth because it gets URL-encoded twice. 
# 한쪽만 쓰고 싶을 때 — 그만큼 프롬프트가 가벼워진다# Use only one half and the prompt gets lighter
OC_KOREA_MCP_TIME=0       → 날씨 3 개만→ weather only
OC_KOREA_MCP_WEATHER=0    → 시간 3 개만→ time only

설계 메모Design notes

기상청 API 를 쓰다 보면 누구나 다시 만나는 것들. The things anyone hits when they wire up this API.

격자 변환Grid projection

기상청은 위경도를 안 받고 자체 격자를 쓴다. Lambert Conformal Conic 을 직접 구현했고 서울 (60,127) · 부산 (98,76) · 제주 (53,38) 표준값과 일치를 확인했다. The API takes its own grid, not lat/lon. The Lambert Conformal Conic projection is implemented here and checked against the published reference points — Seoul (60,127), Busan (98,76), Jeju (53,38).

발표 시각Base time

초단기는 매시 40 분에 생성된다. 정시 직후에 그 시각으로 부르면 빈 응답이 온다. 40 분 이전이면 한 시간 전 발표분을 쓴다. 단기예보는 하루 8 회 발표. Nowcasts are published at :40. Ask for the current hour right after the hour and you get an empty body, so before :40 the previous hour is used. The 3-day forecast publishes eight times a day.

코드값을 서버가 푼다Codes are decoded server-side

SKY=1 을 그대로 넘기면 모델이 해석을 지어낸다. 맑음 으로 풀어서 넘기되, 매핑에 없는 코드는 임의로 해석하지 않고 알 수 없음(값) 으로 표시한다. Handing SKY=1 to a model invites invention. It is decoded here — and codes not in the table are surfaced as unknown rather than guessed at.

단위는 수치에만Units only on numbers

기상청은 강수량 자리에 강수없음 같은 문자열을 섞어 보낸다. 수치일 때만 단위를 붙인다 — 안 그러면 강수없음mm 가 된다. The precipitation field sometimes carries text instead of a number. Units are appended only to numeric values, otherwise you get nonsense like 강수없음mm.

오류를 예외로 던지지 않는다Failures are values, not exceptions

툴은 {"오류": …} 를 돌려준다. 모델이 다음 행동을 정할 수 있어야 하기 때문이다. 키가 없으면 발급 방법까지 같이 알려준다. Tools return a structured error so the model can decide what to do next. A missing key comes back with instructions for getting one.

키는 환경변수로만Keys stay in the environment

httpx 는 INFO 레벨에서 요청 URL 전체를 찍는데 쿼리스트링에 서비스 키가 들어 있다. 그대로 두면 로그에 평문으로 남아서, 이 서버는 해당 로거를 WARNING 으로 낮춘다. httpx logs full request URLs at INFO, and the service key lives in the query string. Left alone it lands in your logs in the clear, so those loggers are turned down.
